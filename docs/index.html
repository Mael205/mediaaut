mediaaut

A personal, self-hosted command-line tool that produces short videos and publishes them to the operator's own YouTube channels.

mediaaut is not a hosted service and has no public sign-up. It runs locally on a single operator's computer and acts only on YouTube channels that the operator personally owns and has authorised through Google OAuth.

What it does

mediaaut turns a written script into a finished vertical video, then uploads it. Every processing step runs on the local machine:

  • Text-to-speech narration using Kokoro-82M, an Apache-2.0 model running offline
  • Word-level subtitle timing via faster-whisper, running locally on the GPU
  • Animated captions rendered by libass, composited with ffmpeg
  • Optional stock background footage from the Pexels and Pixabay APIs
  • Upload to the operator's own YouTube channel via the YouTube Data API v3

How the YouTube Data API is used

The tool uses three endpoints, and no others:

EndpointPurpose
videos.insert Upload a video the operator produced, to the operator's own channel
videos.list Read back the privacy status of the video just uploaded, to report it accurately
channels.list Confirm which channel the stored OAuth token belongs to, before uploading

The tool does not search YouTube, does not read other creators' content, does not collect or display YouTube analytics, and does not store YouTube data beyond what is described in the privacy policy.

Interface

mediaaut is a command-line application. There is no web interface and no server component. A typical session: 

mediaaut auth youtube --channel my-channel
mediaaut make my-channel --script-file script.txt --title "..."
mediaaut publish my-channel-20260828-150709

Synthetic content disclosure

Narration is generated by a text-to-speech model. Every upload therefore sets status.containsSyntheticMedia to true, so that YouTube's altered-or-synthetic-content disclosure is applied automatically rather than left to the operator to remember.
