Privacy Policy

mediaaut · last updated 28 August 2026

1. What mediaaut is

mediaaut is a command-line tool that runs on a single operator's own computer. It is not a hosted service, has no user accounts, no sign-up, and no server that receives data. It is operated by one individual, for that individual's own YouTube channels.

Because there are no third-party users, mediaaut does not collect, process, or store personal information belonging to anyone other than its operator.

2. Data the tool handles

All of the following is stored only on the operator's local machine:

  • Google OAuth tokens. An access token and refresh token, obtained when the operator authorises the tool against their own Google account, are written to a local file. They authorise uploads to the operator's own channels and are never transmitted anywhere except to Google's own API endpoints.
  • Video files, audio, and subtitles produced by the tool.
  • The channel name and channel ID returned by channels.list, used to confirm which channel a stored token belongs to before uploading.
  • The video ID and privacy status returned after each upload, so the tool can report accurately whether the video was published as requested.

3. Data the tool does not handle

  • No YouTube analytics or revenue data is requested or stored.
  • No data about other YouTube users, viewers, or creators is collected.
  • No YouTube content belonging to anyone else is retrieved.
  • No data is sold, shared, or transmitted to any third party.
  • No advertising, tracking, profiling, or analytics of any kind is performed.

4. Use of YouTube API Services

mediaaut uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The operator may revoke mediaaut's access to their Google account at any time via the Google security settings page. Doing so immediately invalidates the stored tokens.

5. Retention and deletion

Stored tokens remain on the local machine until the operator deletes them or revokes access through Google. Deleting the token file, or the mediaaut directory, removes every piece of data the tool retains. There is no remote copy to request deletion of, because no data ever leaves the local machine except API calls made directly to Google.

Should authorisation ever be revoked, or a deletion be requested, all stored YouTube API data is deleted within 30 days, as required by the YouTube API Services Developer Policies. In practice deletion is immediate: revoking access invalidates the token, and the operator holds the only copy.

mediaaut never requests, uses, or stores a Google username or password. Authorisation is obtained solely through Google's OAuth consent screen, and the tool only ever receives the resulting token.

6. Scopes requested

  • youtube.upload — required to upload videos to the operator's own channel.
  • youtube.readonly — used only to confirm which channel the token belongs to, and to read back the privacy status of a video the tool has just uploaded.

No other scope is requested. In particular, no scope granting access to analytics, monetisation, or account management is used.

7. Synthetic content

Narration is produced by a text-to-speech model. Every upload sets status.containsSyntheticMedia to true, applying YouTube's altered-or-synthetic-content disclosure automatically.
