File de mise en ligne

chargement…
Tant que l'audit de l'API n'est pas accordé, une vidéo envoyée par API reste définitivement privée. La mise en ligne passe donc par le site.
  1. Ouvrir YouTube — l'onglet d'envoi s'ouvre
  2. Ouvrir le dossier — glisser le .mp4 dans YouTube
  3. Coller le titre puis la description (boutons Copier)
  4. Publier, ou programmer une date
  5. Marquer comme fait — la vidéo sort de la file
